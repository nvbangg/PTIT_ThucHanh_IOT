## Hướng dẫn cài đặt chung

1. Cài đặt Python 3.x
2. Cài đặt các thư viện cần thiết:
   ```sh
   python -m pip install paho-mqtt
   ```
3. Xem hướng dẫn chi tiết từng buổi trong thư mục tương ứng (ví dụ: [`Buoi1/README.md`](./Buoi1/README.md)).
